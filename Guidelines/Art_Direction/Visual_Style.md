---

## 1. Element Colours

Each element has one colour. Models and VFX use it for emission; UI uses it for element icons and badges.

| Element | Colour |
|---|---|
| Physical | Neutral steel |
| Fire | Orange-red |
| Frost | Cyan |
| Lightning | Yellow |
| Arcane | Purple-magenta |
| Holy | Warm gold-white |
